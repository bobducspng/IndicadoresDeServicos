# Ativos portáteis

Estas são cópias locais dos dois ícones do menu usados originalmente pelos caminhos `/manus-storage/` do WebDev.

Ao hospedar fora do WebDev, copie os PNGs para `client/public/assets/` e altere as constantes `EXPANDED_MARK` e `COLLAPSED_MARK` em `client/src/pages/Home.tsx` conforme o guia `CONTINUAR_COM_OUTRA_IA.md`.
